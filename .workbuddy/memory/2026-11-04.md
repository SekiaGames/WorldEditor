## HiveWE 笔刷与光标错位（已修，4ba7d79）

现象：1.31 原生 BootyBay 里笔刷方块偏离光标约 1-4 格；自带 Test Map 正常。

定位方法：临时加 F4 采样日志（%TEMP%\hivewe_mouse.log 记录鼠标、相机、射线、命中点），
再把命中点反查 war3map.w3e 高度后统计——**这是关键**，纯读代码猜不出来。

结论：物理高度场用 `corners.height` + 刚体原点 z=4，渲染用
`ground_corner_heights = final_ground_height() = height + layer_height - 2.0`，
两者只在 layer==6 时重合。相机俯角 31° 时 1 单位高度差 ≈ 0.83 格横向偏移。
Test Map 是平地、层高恒定所以看不出。

修法：碰撞体改用 ground_corner_heights，刚体原点 z 改 0。
验证：命中点 z - 可视高度 从 2.01 → 0.05。
