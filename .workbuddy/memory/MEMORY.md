# 项目长期约定

## 协作方式（用户明确要求，务必遵守）

- **先说明问题与证据，不主动改代码、不主动提交。**
- 只在用户明确要求时才改代码；改完也不要commit，交给用户决定。
- Agent用人类语言回复客户
- 大范围行为变更（例如多语言字符串同步策略）先给 A/B/C 方案和代价，由用户选。
- 用可验证的数据定位问题（读文件、加日志、跑工具），不要靠猜。
- 不记录历史变更，不记录坑，不做回退兼容。
- 不在代码中写注释，方法/变量名要能直接表现功能特征。
- 执行代码修改前先汇报本轮修改的任务目标，阶段性进展（阶段1/2/3...），方便用户观察Agent是否跑偏。

## 项目目标

- 制作一款基于Godot的War3编辑器
- Extract工程：将暴雪资源解压为Godot资源，封装为extract.pck
    尽可能的将资源拆的细碎，便于灵活组装。
    模型、.tscn、材质、动画、动画库、状态机、粒子特效、wc3.json
- Map工程：负责w3x地图文件和.gmap文件之间的转换
    .gmap文件是Godot资源文件压缩包，包含完整地图资源。
    可以作为独立的exe工具被Editor用于打开地图/保存/另存为
- Editor工程：是地图编辑器，依赖于extract.pck
    可以打开.gmap文件进行编辑、保存
- Wiki工程：是预览工具，依赖于extract.pck
    未开发
- Launcher工程：是Godot启动器
    未开发
