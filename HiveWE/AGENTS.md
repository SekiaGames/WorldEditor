# AGENTS.md

给在这个仓库里工作的 AI 助手的约定。**这些是硬性要求，优先于任何默认行为。**

## 协作约定

1. **先诊断，后动手。** 遇到问题时，先把「是什么问题、证据是什么」讲清楚，等用户决定要不要改。
2. **不主动改代码。** 只有用户明确说「改」「修」「实现」时才动代码。
3. **不主动提交。** 改完代码不要 `git commit`，是否提交、怎么提交由用户决定。
4. **用数据说话，不要猜。** 能通过读文件、加日志、跑工具拿到的事实，不要用推测代替。多次猜错比慢一点更糟。
5. **涉及行为变更时给选项。** 例如「同步到全部语言」还是「只改当前语言」，把 A/B/C 和各自代价摆出来让用户选，不要替用户决定。
6. **不擅自碰用户的数据和产物。** 地图目录、导出的 w3x、构建产物都要先说明再动；确实需要写入时先备份。

## 构建

```cmd
build.bat          # Ninja，产物 build\HiveWE.exe
build.bat deps     # 依赖（一般不需要）
```

生成器固定 Ninja，不调用 `vcvars64.bat`，环境变量由脚本自行拼装。

## 环境限制（避免重复踩坑）

- 安全策略会拦 `reg.exe`、`Add-Type`、`Assembly.LoadWithPartialName`，所以：不能走 vcvars 那条路，也不能截图验证 UI。
- **UI 改动无法由助手自证**，必须让用户跑一次确认外观。
- 验证二进制内容可以用 Python 读文件搜字符串，比 `grep -a` 稳。
- 地图相关的二进制格式（`war3map.w3e` / `.w3i` / `.doo` 等）解析时注意头部字段是**变长**的，不要按固定偏移硬算。
